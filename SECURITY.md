# Security

This repository is research code: a risk model, a measurement testbed and proofs. It is not
a cryptographic library and does not implement any primitive.

If you find a problem that could mislead a migration decision (a scoring error, a
discovery false negative, a proof that does not state what the paper claims), please open
an issue. If it concerns a vulnerability in a third-party product observed with the
testbed, report it to that vendor first and use a private GitHub security advisory here.
